# 🌍 地理奇遇记 · 小念和爸爸的地球探索馆 (`geoverse`)

> 从喜马拉雅到马里亚纳，看着会动的地图与剖面动画，听小念和爸爸一问一答学遍中国与世界地理。

## 这里有什么好玩的？

- **六大地球探索展厅 · 24 集交互式地图与剖面动画问答**
  - 🌋 **板块与山海大剧场**：南美与非洲拼图（大陆漂移）、喜马拉雅造山（海底贝壳）、太平洋火环与马里亚纳海沟、东非大裂谷与红海新大洋
  - 🌦️ **风雨云与极端气候**：地形雨与雨影效应（茂辛拉姆 vs 阿塔卡马）、南北纬 30° 沙漠带、东亚季风绿洲奇迹、厄尔尼诺与拉尼娜暖水跷跷板
  - 🐉 **神州山河与三级阶梯**：西高东低三级阶梯、秦岭—淮河中国南北分界线、喀斯特/丹霞/黄土高原/吐鲁番盆地、胡焕庸线与 400mm 等降水量线
  - 🌊 **大洋、洋流与咽喉海峡**：北大西洋暖流“海上暖气”、尼罗河 vs 亚马孙河与三角洲、马六甲/苏伊士/巴拿马三大海上钥匙、达尔文珊瑚环礁与大堡礁
  - 🧭 **四季、极光与地球时钟**：地轴 23.44° 倾角与相反四季、极昼午夜太阳与极光、24 时区与 180° 国际日界线、月球引潮力与芬迪湾/钱塘江大潮
  - 🏆 **人类家园与世界奇观**：七大洲五大洋世界之最、为什么大都市爱建在河口、赤道雪山乞力马扎罗垂直气候带、北极海冰 vs 南极高原冰盖与秦岭站
- **🌍 自由地球大地图沙盘 (`#/atlas`)**：自由切换板块火环、全球洋流、气候极地、世界大河名城以及中国地形三级阶梯，点击奇观图钉查看经纬坐标与爸爸讲解。
- **🔬 地理原理实验室 & 经纬寻宝 (`#/quiz`)**：亲手拨动地球公转月份、板块运动进度、海风湿度与山高、冬夏季风切换看实时动画；再挑战 5 大关卡 20 道地图扎针寻宝。
- **🎙️ 小念和爸爸全站配音**：统一使用 `edge-tts` 生成「小念（`zh-CN-YunxiaNeural` +0%）& 爸爸（`zh-CN-YunxiNeural` -5%）」MP3 音频，与动画时间轴自动同步。

## 常用命令

```bash
npm install
npm run dev        # 启动本地 Vite 开发服务器
npm run voice      # 增量采集台词并生成小念和爸爸 edge-tts 配音
npm run typecheck  # TypeScript 严格类型检查
npm run check      # 规则守卫与内容一致性校验
npm test           # Node 24 原生测试（含 100% 配音覆盖率检验）
npm run build      # 生产构建到 dist/
npm run smoke      # 无头 Edge/Chrome 桌面 + 手机双端巡检（零报错、零溢出、零文字重叠）
```
