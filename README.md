# 🌍 地理奇遇记 · 小念和爸爸的地球探索馆 (`geoverse`)

> 「奇遇记」系列地理篇：从地球仪经纬网、板块山脉、季风气候、大洋潮汐一路走到神州山河与人类家园，看着会动的地图、24 套地质气候剖面动画与逼真 3D 交互地球仪，听小念和爸爸一问一答把中国与世界地理看个明白。

## 特色内容

- **🪐 奇遇记系列统一的 3D 小星球首屏**：小念和爸爸站在草地小星球上（摆着 23.44° 倾斜地球仪、冒烟小火山、指南针、雪山、热气球、彩虹雨云与遥感小卫星），首帧透明海报瞬时呈现、空闲平滑切入实时 3D，点气泡或点角色就能听父子语音问答。
- **🧭 六站因果递进路线 · 25 集交互式地图与剖面动画问答**
  1. **第 1 站 · 🪐 地球仪与太空时钟（5 集）**：经纬网与墨卡托投影变形（格陵兰 vs 非洲）、23.44° 地轴倾角与相反四季、极昼午夜太阳与极光、24 时区与 180° 国际日界线、月球引潮力与芬迪湾/钱塘江大潮
  2. **第 2 站 · 🌋 板块、山脉与大地骨架（4 集）**：南美与非洲拼图（大陆漂移与海底扩张）、喜马拉雅造山与峰顶海底贝壳、太平洋火环与马里亚纳海沟、东非大裂谷与红海新大洋
  3. **第 3 站 · 🌦️ 风云、雨水与气候密码（5 集）**：迎风坡地形雨与背风坡雨影沙漠、南北纬 30° 副高沙漠带、东亚季风绿洲奇迹、厄尔尼诺与拉尼娜暖水跷跷板、赤道雪山乞力马扎罗垂直气候带
  4. **第 4 站 · 🌊 大洋、江河与极地冰雪（4 集）**：北大西洋暖流“海上暖气”、尼罗河 vs 亚马孙河与河口三角洲、达尔文珊瑚环礁与大堡礁、北冰洋海冰 vs 南极高原冰盖与秦岭站
  5. **第 5 站 · 🐉 走进中国：神州山河（4 集）**：西高东低三级阶梯、秦岭—淮河中国南北分界线、胡焕庸线与 400mm 等降水量线、桂林喀斯特/黄土高原/吐鲁番盆地奇观
  6. **第 6 站 · 🏙️ 人类家园与环游世界（3 集）**：七大洲五大洋世界之最、为什么大都市爱建在河口、马六甲/苏伊士/巴拿马三大海上咽喉
- **🌐 逼真 3D 交互地球仪 · 4 合 1 探索工作台 (`#/globe` / `#/atlas`)**：基于原生 Three.js + 自定义 GLSL 着色器（NASA 卫星白昼地表 + 夜晚城市灯光与胡焕庸线 + 晨昏线暮光 + 海洋太阳高光 + 实时云层 + 菲涅尔大气散射），支持「卫星地球沙盘」「昼夜与四季实验室」「大圆航线与时差测距」「3D 地球扎针寻宝」四大模式，无 WebGL 环境自动降级 2D 平面沙盘。
- **🔬 地理原理实验室 & 经纬寻宝 (`#/quiz`)**：亲手拨动地球公转月份、板块运动进度、海风湿度与山高、冬夏季风切换看实时剖面动画；再挑战 5 大关卡 20 道世界与中国扎针寻宝。
- **📚 权威参考与全站配音**：25 集故事「给大人」100% 附带 NOAA、USGS、NASA、UNESCO、中国气象局等权威参考来源（`sources`），全站 453 条台词由 `edge-tts` 生成「小念（`zh-CN-YunxiaNeural` +0%）& 爸爸（`zh-CN-YunxiNeural` -5%）」MP3 音频并与动画时间轴同步。

## 常用命令

需要 Node.js 22.18+。

```bash
npm install
npm run dev          # 启动本地 Vite 开发服务器
npm run story:new    # 查看六站展厅 ID 与新地理故事脚手架用法
npm run skills:sync  # 同步 skills/ 至 .agents/skills/ 与 .cursor/skills/
npm run voice        # 增量采集台词并生成小念和爸爸 edge-tts 配音
npm run typecheck    # TypeScript 严格类型检查
npm run check        # 规则守卫、权威来源与 Skill 镜像一致性校验
npm test             # Node 原生测试（含 100% 配音覆盖率与 3D 球面几何检验）
npm run build        # 生产构建到 dist/
npm run smoke        # 无头 Edge/Chrome 桌面 + 手机双端巡检（零报错、零溢出、零文字重叠）
```
